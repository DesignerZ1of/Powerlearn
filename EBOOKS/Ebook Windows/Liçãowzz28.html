📘 Lição 28 — Dispositivos externos (pendrive e outros)

Agora você vai aprender a usar algo muito comum no dia a dia do Microsoft Windows:

👉 levar arquivos para fora do computador

🔌 O que são dispositivos externos

São dispositivos que você conecta ao computador para guardar ou transportar arquivos.

💾 Pendrive

💽 HD externo

📱 Celular

📷 Cartão de memória

👉 Funcionam como armazenamento portátil

🖥️ Como conectar

Use a entrada USB e conecte o dispositivo

👉 O sistema reconhece automaticamente

📂 O que acontece

Ele aparece como um novo local no computador

📁 Como acessar

Abra o Explorador de Arquivos e clique no dispositivo

🔄 Como usar

📥 Enviar para o pendrive

Copiar → Colar

📤 Trazer para o computador

Copiar → Colar

⚠️ Remover com segurança

Use a opção antes de retirar

❗ O que NÃO fazer

Não remover direto

Não desconectar usando

🎯 Ideia principal

Permite levar arquivos e usar em outros computadores

🧪 Exercício

1. Abra Arquivos

2. Vá em Documentos e copie o arquivo

3. Cole no Pendrive

4. Vá no Pendrive e copie o arquivo

5. Cole no computador

6. Remova com segurança

⚠️ Use duplo clique em Copiar e Colar
