🧠 Relembrando array

Array serve para:

> guardar listas.

let nomes = ["Carlos", "Ana", "Pedro"];
🧠 Relembrando objeto

Objeto serve para:

> organizar informações relacionadas.

let jogador = { nome: "Carlos", moedas: 100 };
🚀 Misturando os dois

Agora iremos guardar:

> vários objetos dentro de um array.

let jogadores = [ { nome: "Carlos", moedas: 100 }, { nome: "Ana", moedas: 200 } ];
🧠 O que isso significa?

O array:

> guarda vários jogadores.

E cada jogador:

> possui suas próprias informações.

📌 Organização
Posição 0 → Carlos Posição 1 → Ana
🚀 Acessando objeto do array
console.log(jogadores[0]);

📌 Resultado

{ nome: "Carlos", moedas: 100 }
🚀 Acessando informação específica
console.log(jogadores[0].nome);

📌 Resultado

Carlos
🧠 O que aconteceu?

🔹 jogadores[0]

Pega o primeiro objeto.

🔹 .nome

Pega o nome dentro do objeto.

🚀 Atualizando dados
jogadores[0].moedas = jogadores[0].moedas + 50;
🧠 O que acontece?

O sistema:

pega moedas atuais
adiciona 50
atualiza valor

📌 Resultado final

150
🚀 Usando for
for (let i = 0; i < jogadores.length; i++) { console.log(jogadores[i].nome); }
🧠 O que esse código faz?

O for:

percorre o array
pega cada objeto
mostra o nome

📌 Resultado

Carlos Ana
🚀 Sistema simples

Agora iremos criar:

🎮 Sistema de recompensa

let jogadores = [ { nome: "Carlos", moedas: 100 }, { nome: "Ana", moedas: 200 } ]; function recompensa(valor) { for (let i = 0; i < jogadores.length; i++) { jogadores[i].moedas = jogadores[i].moedas + valor; } }
🧠 O que esse sistema faz?

Ele:

percorre todos os jogadores
adiciona moedas para todos

🚀 Executando
recompensa(50); console.log(jogadores);

📌 Resultado final

[ { nome: "Carlos", moedas: 150 }, { nome: "Ana", moedas: 250 } ]
🧠 Pensamento importante

> Arrays organizam listas.

> Objetos organizam informações.

> Arrays + objetos são uma das estruturas mais usadas na programação.
