🧠 O que é "for"

O for é uma estrutura de repetição.

Ele é usado quando você já sabe:

• Onde começa
• Até onde vai
• Como o valor muda

---
📌 Estrutura do for
for (início; condição; mudança) { }
🔍 O que cada parte faz

Início → Valor inicial

O início sempre vai estar no começo dos parênteses() e antes do ; .

Ele é o valor inicial, é o valor que está antes do código. IMPORTANTE: A variável criada no código "for" só pode ser usada dentro dele e não em outros códigos

Condição → Até quando continua

Ele vem depois do ; e acaba no ;

Nele mostra o que é necessário para o código acontecer.

Mudança → Atualização do valor

Ele vem depois do ; e acaba no ()

Ele serve para mudar o valor inicial.

---
💻 Código (1º da aula)
for (let i = 1; i <= 3; i++) { console.log(i); }
---
🧠 Tradução

Cria a variável "i" com o valor 1 (Início)

Mostra que a variável "i" tem que ter o valor menor ou igual a 3 (Condição)

Nós aumentamos o valor +1 (Mudança)

NomedaVariável++

E finalizamos com o console.log para nos mostrar o resultado

---
📌 O que significa i++
i++

É uma forma resumida de:

i = i + 1

Ou seja: pega o valor atual e soma +1

---
🧠 Por que usamos for

Porque ele deixa:

início
condição
mudança

Tudo organizado em uma linha.

---
🔥 Diferença de while e for

while → “Não sei exatamente quantas vezes vai repetir”

let numero = 1; while (numero <= 3) { console.log(numero); numero = numero + 1; }

O while funciona assim: “Enquanto isso for verdadeiro → continue”

Ele é mais manual.

Você separa:

início
condição
mudança

---

for → “Já sei quantas vezes quero repetir”

for (let i = 1; i <= 3; i++) { console.log(i); }

O for é mais organizado.

Ele junta:

início
condição
mudança

Tudo em uma linha.

---
💡 Dica importante

Antes de usar for, pense:

“Quantas vezes isso precisa repetir?”

---
🎯 Fechamento

while controla na mão.
for organiza o controle.
