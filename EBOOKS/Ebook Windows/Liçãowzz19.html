⚡ Lição 19 — Atalhos e botões

👉 fazer tudo mais rápido, com menos esforço e mais controle

⚡ O que são atalhos

Atalhos são combinações de teclas que executam ações rapidamente.

⌨️ Atalhos essenciais

Ctrl + C → copiar

Ctrl + V → colar

Ctrl + X → recortar

Ctrl + Z → desfazer

Ctrl + Y → refazer

🔍 Seleção

Ctrl + A → selecionar tudo

📂 Sistema

Ctrl + S → salvar

Alt + F4 → fechar programa

NAVEGADOR📡

Ctrl + T → nova aba

Ctrl + W → fechar aba

Ctrl + Shift + T → reabrir aba fachada

Ctrl + L → ir para a barra de endereço

🖱️ Botões

Clique → selecionar

Duplo clique → abrir

⚠️ Erros comuns

Não confundir copiar com recortar

Não fechar sem salvar

🎯 Ideia principal

Atalhos = velocidade | Botões = precisão

🧪 Exercício

1. Abra o arquivo de texto

2. Digite algo

3. Use:

Ctrl + A

Ctrl + C

Ctrl + V

Ctrl + X

4. Feche com Alt + F4
