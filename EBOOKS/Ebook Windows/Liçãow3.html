🖥️ Lição 3 — Conhecendo o Windows (interface e ferramentas)

Agora que você já instalou o Microsoft Windows, o próximo passo é simples: entender o que está na sua tela e para que serve cada coisa.

Sem isso, você usa. Com isso, você controla.

🧭 🖥️ Área de Trabalho (Desktop)

É a tela principal.

👉 Aqui ficam:

  • Atalhos
  • Arquivos
  • Programas
💡 É o seu “ponto de partida”.
📂 Explorador de Arquivos

Ícone de pasta 📁

Serve para ver e organizar arquivos

👉 Aqui você:

  • Cria pastas
  • Move arquivos
  • Organiza tudo
💡 Sem isso, vira bagunça.
🪟 Menu Iniciar

Fica no canto inferior esquerdo

Abre quando você clica no botão do Windows

👉 Serve para:

  • Procurar programas
  • Acessar configurações
  • Desligar o PC
🔎 Barra de Pesquisa

Fica na barra inferior

👉 Você pode:

  • Pesquisar arquivos
  • Abrir programas rápido
  • Buscar configurações
💡 Economiza tempo.
📌 Barra de Tarefas

Fica na parte de baixo da tela

👉 Mostra:

  • Programas abertos
  • Apps fixados
💡 É o seu “controle rápido”.
⚙️ Configurações

Onde você ajusta o sistema

👉 Aqui você muda:

  • Wi-Fi
  • Tela
  • Contas
  • Sistema
🔔 Área de Notificações

Canto direito inferior

👉 Mostra:

  • Internet
  • Som
  • Bateria
  • Avisos
🧠 Como tudo se conecta

Menu Iniciar → abre tudo

Barra de tarefas → controla o que está aberto

Explorador → organiza arquivos

Configurações → ajusta o sistema

👉 Cada parte tem função clara. Juntas, controlam tudo.

🎯 O que você precisa entender

Você não precisa decorar tudo.

Só precisa saber:

  • Onde clicar
  • Onde procurar
  • Pra que cada coisa serve

Depois disso, você para de “clicar perdido” e começa a usar com intenção.
