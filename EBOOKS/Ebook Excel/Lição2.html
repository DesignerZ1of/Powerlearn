Lição 2 — Estrutura da Planilha (do jeito certo)

Vamos começar com a estrutura de uma Planilha, aonde cada Coluna e linha tem uma função.

Você deve saber como usar colunas e linhas, para se organizar no Excel.

Pense no Excel como uma cidade.

Colunas São as ruas → Cada rua tem uma função (Preço, Nome, Quantidade).
Linhas São as casas → Cada casa é um item completo.
Células São os cômodos → Aqui deve ter um dado por cômodo.

Usando o Excel

Com forme aos exemplos inteiros, vamos pensar de forma lógica, aonde usaremos o excel como se tivéssemos uma loja.

Nós devemos usar as colunas das seguintes formas:

A → Produto
B → Preço
C → Quantidade

Selecionar

Irei te mostrar uma dica, para você selecionar células mais rápidamente

Clicar → Seleciona uma célula
Clicar + Arrastar → Seleciona várias células
Letra da coluna → Seleciona somente a coluna; a coluna inteira

Inserir (expandir a cidade)

Irei te mostrar uma técnica, que pode ser usada tanto para criar novas colunas ou mudar as informações de lugar

A Primeira técnica é a de você mudar de lugar todas as informações da coluna B para a coluna C ou A.
(IMPORTANTE: Isso só é mais usado para planilhas pequenas para que não mova informações que estejam mais escondidas e que não deviam ser mudadas de lugar)
Clique na coluna B → Inserir
Nova rua aparece, tudo continua no lugar

Dúvidas rápidas

Por que selecionar antes?
Porque o Excel só age onde você apontar.

Delete ou Excluir?
Delete esvazia a célula.
Excluir muda a estrutura da planilha.

Por que inserir coluna?
Para corrigir a estrutura sem perder dados.
