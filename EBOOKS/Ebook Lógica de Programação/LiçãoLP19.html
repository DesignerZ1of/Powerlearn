🧠 O que você vai aprender aqui

Como funciona a estrutura da classe

O que faz class

O que faz constructor()

O que significa this

Como os valores são colocados no objeto

🧩 Tipo de lógica usado

🔹 Lógica de Modelos

> Criar objetos organizados usando uma estrutura.

🧠 Estrutura da classe

💻 Estrutura básica

class Nome { }

🧠 Explicando

🔹 class

Código usado para:

> criar a classe.

🔹 Nome

Lugar onde você escreve:

> o nome da classe.

💻 Exemplo real

class Jogador { }

🧠 O que isso cria?

Uma classe chamada:

> Jogador

🧠 Entrando no constructor

💻 Estrutura

constructor() { }

🧠 O que ele faz?

O constructor() serve para:

> receber os valores iniciais do objeto.

📌 Dentro do ( )

Dentro do constructor():

> você coloca os nomes que receberão valores.

💻 Exemplo

constructor(nome, pontos)

🧠 O que isso significa?

O objeto agora poderá receber:

nome
pontos

🧠 Entrando no this

💻 Estrutura

this.nome = nome;

🧠 O que isso significa?

🔹 this.nome

Lugar do objeto onde o valor será guardado.

🔹 = nome

Valor recebido pelo constructor.

📌 Ideia simples

this.nome = nome;

Significa:

> “o nome desse objeto receberá o valor enviado”.

💻 Classe completa

class Jogador { constructor(nome, pontos) { this.nome = nome; this.pontos = pontos; } }

🧠 O que essa classe faz?

Ela cria objetos com:

nome
pontos

🚀 Criando objeto

💻 Código

let jogador1 = new Jogador("Carlos", 100);

🧠 O que acontece?

🔹 nome

Recebe:

"Carlos"

🔹 pontos

Recebe:

100

🧠 Resultado final do objeto

nome = "Carlos" pontos = 100

🧠 Como acessar

💻 Exemplo

console.log(jogador1.nome);

🧠 Resultado

Carlos

⚠️ Erro comum

Confundir:

parâmetro do constructor
com
local onde o valor será salvo

📌 Diferença importante

Dentro do constructor

constructor(nome)

👉 recebe valor

Dentro do this

this.nome

👉 guarda valor no objeto

🎯 Resumo final

> class cria a classe.
constructor() recebe valores.
this guarda os valores no objeto.
