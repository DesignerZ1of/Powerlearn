🔹 Lógica de Organização de Dados

> Guardar várias informações relacionadas no mesmo lugar.

🧠 O que é um objeto?

Objeto é uma estrutura usada para guardar informações organizadas.

📌 Ideia simples

Enquanto o array guarda:

> listas

O objeto guarda:

> características

💻 Código (1º da aula)

let jogador = { nome: "Carlos", idade: 18, pontos: 100 };

🧠 O que está acontecendo

O objeto chamado:

> jogador

Está guardando:

nome
idade
pontos

Tudo junto e organizado.

📌 Como pensar no objeto

Objeto funciona como:

> uma ficha de informações

🧠 O que são as chaves { }

No objeto:

{ }

As chaves agrupam todas as informações.

🧠 O que significa :

O : separa:

nome da característica
valor da característica

📌 Exemplo

nome: "Carlos"

Significa:

> a característica “nome” possui valor “Carlos”.

🧠 Como acessar informações

Usamos:

.

💻 Exemplo

console.log(jogador.nome);

🧠 Resultado

Aparece:

Carlos

📌 Outro exemplo

console.log(jogador.pontos);

Resultado:

100

🧠 Diferença entre array e objeto

Array

> organizado por posições

nomes[0]

Objeto

> organizado por características

jogador.nome

🧠 Quando objetos são usados?

jogador
usuário
