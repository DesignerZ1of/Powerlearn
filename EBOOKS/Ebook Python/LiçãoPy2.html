🧠 O que é uma variável?

Uma variável é um lugar que serve para Guardar informações na memória.

Elas guardam informações que o programa vai usar para realizar tarefas,como cálculos e mostrar mensagens. Sem variáveis, o programa não tem memória, e nenhuma informação para usar e realizar essas Tarefas.

O Valor das Variáveis podem mudar, conforme for feito o código. Por isso do nome Variável.(Pode parecer só uma pequena informação mas ela acrescenta muitas possibilidades, por isso guarde essa informação.)
nome = "Carlos"

Sempre use essa estrutura para quando for criar uma Variável:

  • nome → nome da variável
  • = → significa "recebe", ou seja o que vem depois é o valor da variável
  • "Carlos" → valor guardado
📦 Pense como uma caixa

Uma variável funciona como uma caixa com etiqueta.

idade = 20

A caixa chamada:

idade

está guardando:

20
⚠ O sinal =

No Python:

nome = "Ana"

O "=" significa:

“guardar”

Não significa igualdade como na matemática.

🔥 Mostrando variáveis
nome = "Lucas"

print(nome)
▶ Lucas
🔢 Tipos básicos de dados

Uma variável pode guardar diferentes tipos de dados, aonde cada um tem sua forma de usar, por isso se atente a cada um deles.

📝 Texto (string)

Nele usamos as aspas "" para mostrar ao Python que o valor da variável é um texto.
cidade = "Rio de Janeiro"

🔢 Número inteiro (int)

idade = 18

🔥 Número decimal (float)

Nele nós usamos o ponto para fazer a função da vírgula, sempre lembre disso quando for usá-lo. Não é Vírgula é Ponto.
altura = 1.75

✅ Verdadeiro ou falso (bool)

Nele usamos só dois tipos de valor; pois o valor ou é Verdadeiro ou é Falso. Verdadeiro → True Falso → False
aprovado = True
🧠 Python lê de cima para baixo
nome = "Carlos"

print(nome)
▶ Carlos

Primeiro:

  • guarda "Carlos"
  • depois mostra na tela
⚠ Espaços ainda são importantes

Os espaços fazem parte da estrutura principal do Python.

Sabendo usar os espaços corretamente você entende grande parte da linguagem.

✅ Correto:

if True:
    nome = "João"
    print(nome)

❌ Errado:

if True:
nome = "João"
▶ IndentationError
🔥 Mudando valores
Como foi falado lá em cima, nós podemos mudar os valores de uma variável no mesmo código, de uma forma simples.

Como Mudar os Valores

Você pode mudar o valor de uma variável, escrevendo ela novamente só que com um valor diferente.
idade = 18

print(idade)

idade = 25

print(idade)
▶ 18
▶ 25
💡 Juntando texto e variável
nome = "Pedro"

print("Olá", nome)
▶ Olá Pedro
