💽 Lição 16 — Espaço do computador (armazenamento)

📦 O que é armazenamento

O armazenamento é o espaço interno do computador onde todos os arquivos são guardados.

👉 Pense assim:
O computador é como um armário, e o armazenamento é o espaço dentro dele.
Tudo que você salva — documentos, imagens, vídeos e programas — ocupa esse espaço.

--- 💽 Tipos de armazenamento

Existem dois tipos mais comuns:

HD (Disco Rígido) → mais antigo, mais lento
SSD → mais moderno, mais rápido

👉 Ambos servem para guardar arquivos, mas o SSD deixa o computador mais rápido.

--- 📊 Arquivos ocupam espaço

Cada arquivo usa uma parte do armazenamento:

Texto → ocupa pouco espaço
Imagem → ocupa mais
Vídeo → ocupa muito mais

👉 Quanto mais arquivos você tiver, menos espaço sobra.

--- 🖥️ Como ver o espaço do computador

1. Abra o Explorador de Arquivos
2. Clique em Este Computador
3. Observe o disco (ex: Disco Local)

Lá você verá:
Espaço usado
Espaço livre

--- ⚠️ Quando o espaço está cheio

Se o armazenamento ficar cheio:

O computador pode ficar lento
Pode não conseguir salvar arquivos
Alguns programas podem travar

👉 Isso acontece porque não há espaço disponível.

--- 🧹 Noção básica de limpeza

Para evitar problemas:

Apague arquivos que não usa
Limpe a pasta Downloads
Evite guardar arquivos grandes desnecessários
