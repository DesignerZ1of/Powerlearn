• O que é um parâmetro
• Como a função recebe informações
• Como enviar valores diferentes para a mesma função
• Como o parâmetro muda de valor a cada execução

🧩 Tipo de lógica usado

🔹 Lógica de Comunicação

> Enviar informações para a função usar.

🧠 O que é um parâmetro?

> O parâmetro funciona como: uma variável vazia esperando um valor.

💻 Exemplo simples

function falar(nome) { console.log(nome); }

🧠 O que está acontecendo?

🔹 nome

É o parâmetro.

Nesse momento:

> ele ainda está vazio.

🚀 Enviando um valor

falar("Carlos");

🧠 O que acontece?

A função recebe:

"Carlos"

Então:

> nome passa a valer "Carlos"

📌 Como pensar nisso

É como se fosse:

nome = "Carlos"

Só que:

> isso acontece dentro da função.

🧠 O parâmetro escolhe sozinho?

❌ Não.

O parâmetro:

> apenas recebe o valor enviado.

💻 Outro exemplo

falar("Ana");

Agora:

> nome = "Ana"

🧠 Importante

O valor antigo:

> é trocado pelo novo.

🚀 Chamando várias vezes

function nome(pessoa) { console.log(pessoa); } nome("Carlos"); nome("Ana");

🧠 O que acontece?

Primeira execução:

> pessoa = "Carlos"

Segunda execução:

> pessoa = "Ana"

📌 Resultado

Carlos Ana

🧠 Ideia principal

Cada vez que a função é chamada:

> o parâmetro recebe um novo valor.

💻 Exemplo mais completo

function mensagem(nome) { console.log("Olá " + nome); } mensagem("Carlos"); mensagem("Ana");

🧠 Resultado

Olá Carlos Olá Ana

📌 Fluxo simples

cria função
cria parâmetro vazio
envia valor
parâmetro recebe valor
função usa valor

⚠️ Erro comum

Pensar que:

> o parâmetro cria ou escolhe valores sozinho.

❌ Não.

Você precisa:

> enviar os valores manualmente.

🎯 Fechamento

> O parâmetro é uma variável vazia. A função espera você enviar um valor.

🧠 1. Reforço — Criar código usando for

Crie um for que mostre:

1 2 3

🧠 2. Criar função com parâmetro

Crie uma função chamada:

mensagem

Com o parâmetro:

nome

A função deve mostrar:

Olá + nome

Depois execute a função enviando:

"Carlos"

🧠 3. Função com parâmetro + repetição

Crie uma função chamada:

falar

Com o parâmetro:

nome

Depois use:

for

Para executar a função 3 vezes.

A função deve mostrar:

Olá + nome
