📘 Lição 3 — Entrada de Dados com input()

Nesta aula você vai aprender:

  • Como receber dados do usuário
  • O comando input()
  • Guardar respostas em variáveis
🧠 O que é input()?

Nesta aula o código que será aprendido será o input() que serve para:

💡 Receber informações digitadas pelo usuário.

Nesse código, colocamos algo dentro dos parênteses () lembrando que ser for algum texto deve colocar aspas ""; aonde você deve usa-lo quando o usuário tem que colocar alguma informação.

nome = input("Digite seu nome: ")

print(nome)
▶ Digite seu nome:
💻 Como funciona?

Passo 1 → Python mostra a mensagem "nome"

Passo 2 → O usuário digita algo.

Passo 3 → O valor é guardado na variável.

Passo 4 → O programa usa esse valor.

Estrutura

Ok, agora irei te ensinar baseado nesse exemplo

1. Nós começamos esse código criando uma variável chamado "nome"

2. E deifinimos que o valor dessa variável será o que for digitado no "input()"

3. Mas que por enquanto o valor será "Digite seu nome: "

4. Mas que depois será trocado pelo nome do usuário

5. E finalizamos mostrando na tela

🔥 Exemplo completo
nome = input("Digite seu nome: ")

print("Olá", nome)
▶ Olá Carlos
⚠ IMPORTANTE

Tudo que vem do input() vira TEXTO.

Mesmo números.

idade = input("Digite sua idade: ")

print(idade)
▶ 18

O Python entende:

💡 "18" como TEXTO.
🔥 Convertendo para número

Para resolvermos isso colocamos "int(" para que Python possa entender que pode entrar números

Número inteiro:

idade = int( input( "Digite sua idade: " ))

Número decimal:

altura = float( input( "Digite sua altura: " ))
🧪 Exemplo com soma
numero1 = int( input( "Digite um número: " ))

numero2 = int( input( "Digite outro número: " ))

resultado = numero1 + numero2

print(resultado)
▶ 20
⚠ Sem int() dá problema
numero1 = input("Número: ")

numero2 = input("Número: ")

print(numero1 + numero2)
▶ 1010

Porque o Python juntou textos.
