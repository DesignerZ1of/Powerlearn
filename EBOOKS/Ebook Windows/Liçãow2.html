⚙️ Lição 2 — O que realmente importa depois de instalar o Windows

Instalar o Microsoft Windows é só o começo. Se você parar ali, o computador funciona — mas não está pronto.

Aqui está o que realmente faz diferença:

🌐 1. Conectar à internet (essencial)

Sem isso, você fica travado.

  • Clique no Wi-Fi
  • Conecte na sua rede
👉 É o que libera todo o resto.
🔄 2. Atualizar o sistema (evita problema)

Vá em Configurações > Windows Update

Clique em Verificar atualizações

👉 Isso resolve erros, melhora desempenho e segurança.
🧠 3. Verificar se tudo está funcionando (drivers)

Teste:

  • Som 🔊
  • Internet 🌐
  • Tela/resolução 🖥️

👉 Se algo não funcionar, provavelmente é driver.

💡 Na maioria dos casos o próprio Windows resolve sozinho após atualizar.

⚡ 4. Instalar o básico (pra usar de verdade)

Sem isso, o PC fica “vazio”.

  • Navegador (ex: Google Chrome)
  • Um app pra PDF
  • Algum app que você usa (estudo, trabalho, etc.)
🧹 5. Ajuste rápido que muda tudo
  • Coloque idioma certo
  • Ajuste brilho
  • Organize a área de trabalho
👉 Pequeno detalhe, grande diferença no uso.
⚠️ O que a maioria ignora (erro comum)
A pessoa instala o Windows e já sai usando.

Resultado:

PC lento
Coisas não funcionando
Problemas simples virando dor de cabeça
