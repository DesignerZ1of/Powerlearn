📘 LIÇÃO 5 — Repetição (Parte 1)

🔹 Lógica de Repetição

Fazer algo várias vezes automaticamente

🧠 Ideia central:

Enquanto algo for verdadeiro → continue

Para fazermos isso usaremos um código:

while
🧠 O que significa while

while = “enquanto”

Nós usamos "while" junto com uma estrutura onde cada símbolo ou palavra serve para algo

Estrutura:
while (condição) { ações }

while → Chama o comando

() → Dentro dos parênteses nós botamos a condição, ou seja, significa: O que é necessário para que aconteça o código?

{} → Caso o que esteja em condição seja verdadeiro, todas as ações que estiver nas {} ocorrerá várias vezes.

Essa é a estrutura da Lição de Hoje, bem simples mas complexa ao mesmo tempo

💻 Exemplo Completo do Código
let numero = 1; while (numero <= 5) { console.log(numero); numero = numero + 1; }
📌 VAMOS ENTENDE LO

No código criamos uma variável chamada "numero" com o valor 1.
Até aqui aprendemos!

Logo após começa com "while" para iniciar uma repetição; mas há um parenteses falando o seguinte:

Se a variável numero (valor 1) for menor ou igual a 5 é executada a ação

Como 1 é menor que 5, será executada a ação!!

A ação é:

console.log(numero)

Ou seja será mostrado o valor da variável numero, que no caso é 1.

📌⌨️ MAIS O QUE É: numero = numero + 1

Isso é algo que você tem que guardar, é uma grande informação:

O valor das variáveis mudam

Uma variável não é fixa.
Ela pode mudar de valor ao longo do código.

Como isso funciona?

Você pega o valor atual e atualiza ele.

numero = numero + 1

Significa: pega o valor atual e soma +1

💻 Exemplo
let numero = 1; console.log(numero); numero = numero + 1; console.log(numero);
🧠 O que acontece

Primeiro mostra: 1
Depois atualiza → vira 2
Mostra de novo: 2

🎯 Resumo

A variável começa com um valor, e pode mudar durante o programa.

No começo nós criamos uma variável, depois repetimos elas somando (+1) e o código termina mostrando: 1,2,3,4,5
