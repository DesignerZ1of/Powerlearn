Como usar for com arrays

---
🧩 Tipo de lógica usado

🔹 Lógica de Estrutura de Dados

Percorrer e verificar informações automaticamente.

---
🧠 Relembrando

Array é uma lista de valores.

let nomes = ["Ana", "Carlos", "João"];
---
🧠 O problema

Sem repetição:

você teria que acessar posição por posição manualmente.

---
🚀 Usando for com arrays
let nomes = ["Ana", "Carlos", "João"]; for (let i = 0; i < nomes.length; i++) { console.log(nomes[i]); }
---
🧠 O que acontece

começa no 0

percorre todas as posições

mostra cada valor automaticamente

---
📌 Entendendo melhor

🔹 i

Controla a posição atual.

🔹 nomes.length

Mostra o tamanho do array.

🔹 nomes[i]

Acessa a posição atual.

---
🧠 Quando usar for com arrays?

Quando:

você quer percorrer a lista inteira.

---
🔁 Usando while com arrays
let nomes = ["Ana", "Carlos", "João"]; let i = 0; while (i < nomes.length) { console.log(nomes[i]); i++; }
---
🧠 O que acontece

começa na posição 0

verifica se ainda existe posição

mostra o valor

aumenta +1

repete

---
⚖️ Diferença entre for e while com arrays

for

mais organizado

melhor para listas

while

mais manual

mais controle

---
🧠 Verificando se existe

Para verificar se um valor existe usamos:

.includes()
---
💻 Exemplo
let nomes = ["Ana", "Carlos", "João"]; console.log(nomes.includes("Carlos"));
---
🧠 Resultado

Aparece:

true

Porque:

“Carlos” existe no array.

---
⚠️ E se não existir?
console.log(nomes.includes("Pedro"));

Resultado:

false
---
🧠 O que .includes() retorna?

true → existe

false → não existe

---
📌 Diferença importante

.indexOf()

procura posição

.includes()

verifica existência

---
🎯 Fechamento

Arrays guardam dados.

Repetição percorre dados.

Includes verifica dados.

🧪 Exercícios de Código

1. Crie um FOR com Array

Crie um array chamado frutas com:

"Maçã", "Banana", "Uva"

Depois:

Use um for para mostrar todas as frutas.

📌 Exemplo para seguir:

let nomes = ["Ana", "Carlos"]; for (let i = 0; i < nomes.length; i++) { console.log(nomes[i]); }

2. Procurando posição com indexOf()

Crie um array chamado nomes com:

"Ana", "Carlos", "João"

Depois:

Mostre a posição de "Carlos" usando:

.indexOf()

📌 Exemplo para seguir:

let numeros = [10, 20, 30]; console.log(numeros.indexOf(20));
