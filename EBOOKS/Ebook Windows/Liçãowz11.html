📁 Lição 11 — Criando pastas e arquivos

Agora que você já sabe como o computador organiza tudo e como usar o Explorador de Arquivos no Microsoft Windows, chegou a parte mais importante: começar a criar e organizar suas próprias coisas.

📁 Criando pastas

As pastas servem para organizar arquivos. Sem elas, tudo ficaria misturado.

1. Abra o Explorador de Arquivos

2. Vá até o local desejado (ex: Documentos)

3. Clique com o botão direito em um espaço vazio

4. Clique em Novo > Pasta

5. Digite o nome da pasta

6. Pressione Enter

🧠 Como nomear pastas (importante)

Exemplos bons: Escola, Fotos, Trabalhos

Exemplos ruins: Pasta1, Coisas, Novo

📝 Criando arquivos

Arquivos são o conteúdo que você cria dentro do computador.

⚙️ Como criar um arquivo

1. Clique com o botão direito dentro de uma pasta

2. Clique em Novo

3. Escolha o tipo de arquivo

4. Digite o nome

5. Pressione Enter

💾 Outra forma

Através de programas → criar → salvar → escolher local

🎯 Ideia principal da lição

Pastas organizam. Arquivos guardam conteúdo.

🧪 Exercício — Criar arquivo dentro da pasta

1. Abra o Explorador
2. Entre na pasta
3. Clique com botão direito
4. Vá em Novo → Documento de texto
5. Crie: anotacoes.txt
