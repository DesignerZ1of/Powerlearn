Como o programa toma decisões

---
🧩 Tipo de lógica usado

🔹 Lógica Condicional

O programa escolhe um caminho dependendo da condição.

---
🧠 O que é if

if significa:

“se”

---
📌 O que ele faz

O if verifica uma condição.

Se a condição for verdadeira:

o código dentro dele executa.

---
💻 Código (1º da aula)
let idade = 18; if (idade >= 18) { console.log("Pode entrar"); }
---
🧠 Tradução

Se a idade for maior ou igual a 18 → mostre “Pode entrar”

---
🔍 O que está sendo usado aqui

variável → guarda idade

operador >= → compara

if → decide

console.log() → mostra resultado

---
🧠 O que é else

else significa:

“senão”

---
📌 O que ele faz

O else executa quando o if for falso.

---
💻 Código (2º da aula)
let idade = 15; if (idade >= 18) { console.log("Pode entrar"); } else { console.log("Não pode entrar"); }
---
🧠 Tradução

se idade ≥ 18 → pode entrar

senão → não pode entrar

---
⚠️ IMPORTANTE

ESTRUTURA

if (condição) { ação } else { ação }

No else não tem "condição" pois já está no if.

O else complementa o if.

---
🧠 Verdadeiro e falso

Toda condição gera:

verdadeiro
ou
falso

---
📌 Exemplos

10 > 5 → verdadeiro

5 > 10 → falso

18 == 18 → verdadeiro

---
🧠 Quando usamos condição?

Condições são usadas quando:

o programa precisa decidir algo.

---
📌 Exemplos reais

verificar idade

verificar senha

verificar pontos

verificar vida

🧪 Exercício 1 — Criando um IF

Crie um código que:

✔ Crie uma variável chamada idade com valor 18

✔ Use if para verificar se pode entrar
