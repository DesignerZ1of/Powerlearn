📘 LIÇÃO 23 — Sistemas na Prática + Objetos na Prática

🧠 Objetivo da aula

Agora você começará:

> a organizar sistemas melhor.

Até agora:

• usamos arrays separados
• nomes em um array
• moedas em outro

Agora:

> iremos juntar informações usando objetos.

📌 Conteúdos usados

• objetos
• arrays
• funções
• parâmetros
• .includes()
• .indexOf()
• atualização de dados
• verificações

🧠 Relembrando objetos

Objeto serve para:

> guardar informações relacionadas juntas.

let jogador = { nome: "Carlos", moedas: 100, vida: 50 };
🧠 Acessando informações
console.log(jogador.nome);

📌 Resultado:

Carlos

🧠 Atualizando informações
jogador.moedas = jogador.moedas + 50;

🧠 O que acontece?

• pega moedas atuais
• adiciona 50
• atualiza valor

📌 Resultado final: 150

🚀 Criando sistema simples

🎮 Sistema de moedas com objetos
🚀 ETAPA 1 — Criando objeto
let jogador = { nome: "Carlos", moedas: 100 };
🚀 ETAPA 2 — Criando função
function adicionarMoedas(valor) { }

🧠 O que essa função fará?

> ela irá adicionar moedas ao jogador.

🚀 ETAPA 3 — Atualizando moedas
jogador.moedas = jogador.moedas + valor;
🚀 ETAPA 4 — Código completo
let jogador = { nome: "Carlos", moedas: 100 }; function adicionarMoedas(valor) { jogador.moedas = jogador.moedas + valor; } adicionarMoedas(50); console.log(jogador.moedas);

📌 Resultado: 150

🧠 O que mudou comparado aos arrays?

Antes:

let jogadores = ["Carlos"]; let moedas = [100];

Agora:

let jogador = { nome: "Carlos", moedas: 100 };

👉 Tudo fica organizado em um único objeto.

🎯 Vantagem dos objetos

• mais organizado
• mais fácil de entender
• mais parecido com sistemas reais

🧠 Pensamento importante

> Sistemas grandes precisam de organização.

🧠 Dica 1 — “uma coisa = um objeto”

Se algo no seu sistema tem várias informações juntas, ele deve virar um objeto.

let jogador = { nome: "Carlos", moedas: 100, vida: 50 };
📌 Exemplo errado
let nome = "Carlos"; let moedas = 100; let vida = 50;
📌 Exemplo correto
let jogador = { nome: "Carlos", moedas: 100, vida: 50 };
🧠 Dica 2 — Nomeie objetos como coisas reais

O nome do objeto deve representar algo do sistema.

let a = { n: "Carlos", m: 100 };

❌ ruim

let jogador = { nome: "Carlos", moedas: 100 };

✔ correto

🧪 DESAFIO FINAL (MELHORADO)

🎮 Sistema completo de personagem

Agora você vai criar um sistema REAL de personagem.

📌 REGRAS DO SISTEMA:

✔ Criar um objeto chamado personagem
✔ Deve conter: nome, vida e moedas
✔ Criar função chamada ganharMoedas
✔ A função deve receber um valor como parâmetro
✔ Adicionar moedas ao personagem
✔ Criar função chamada tomarDano
✔ Reduzir vida do personagem
✔ Usar acesso com ponto (.)
✔ Mostrar tudo com console.log()

💡 EXIGÊNCIA EXTRA (IMPORTANTE)

O sistema deve funcionar com pelo menos 2 chamadas de função diferentes.

Exemplo:

ganharMoedas(50); tomarDano(20);
