📘 LIÇÃO 1 — O que é Lógica de Programação

🧠 Definição direta

Lógica de programação é a habilidade de pensar passo a passo para resolver um problema.

> Antes do código existir, a solução já precisa existir na sua cabeça.

A Lógica de Programação pode ser dividida em tópicos aonde você aprenderá cada um deles nesse Ebook:

Lógica Sequencial
Lógica Condicional
Lógica de Repetição
Lógica de Estrutura de Dados
Lógica de Funções
Lógica Algorítmica
Lógica de Eventos
POO (Programação Orientada a Objetos)

⚙️ Como qualquer programa funciona

Todo programa, sem exceção, segue 3 etapas:

1. Entrada

Receber dados

Ex: idade, nome, comando do jogador

2. Processamento

Pensar / decidir o que fazer

3. Saída

Mostrar o resultado

🧩 Exemplo simples (vida real)

Situação:

> Uma pessoa quer entrar em um evento

Lógica:

1. Recebe a idade (entrada)

2. Verifica se é maior de idade (processamento)

3. Mostra resultado (saída)

💻 Exemplo em código (1º código da aula)
let idade = 18;

if (idade >= 18) {
  console.log("Pode entrar");
} else {
  console.log("Não pode entrar");
}
🧠 Mesma lógica em português (importante)

> Se a idade for maior ou igual a 18 → pode entrar

Senão → não pode entrar

👉 Isso é lógica. O código é só a tradução.

🎮 Trazendo pro seu mundo (jogo)

Situação:

> Jogador quer desbloquear um drible

Lógica:

1. Recebe pontos de treino

2. Verifica se tem o suficiente

3. Libera ou não

👉 Você já está pensando como programador aqui.

🧱 O erro mais comum

Começar direto no código sem pensar.

Resultado:

Travar

Copiar sem entender

Depender sempre de ajuda

📌 Regra de ouro

> Se você não consegue explicar a lógica em português,

você não entendeu o problema.
