Lição 4 — Organização de Planilhas

O que são Planilhas?

É o arquivo na qual estamos trabalhando, aonde nele nós organizamos dados e informações, calculamos valores, e organizamos nossas ideias.

Por que planilhas existem?

Uma planilha não é “mais uma aba”.
Ela serve para separar contextos.

Regra mental:

Uma planilha = Um tipo de informação.

Misturar tudo em uma única planilha funciona só no começo.
Quando o arquivo cresce, vira confusão.

Como pensar antes de criar planilhas

Antes de clicar em “+”, pense:

  • Isso é o mesmo assunto ou outro assunto?
  • Esses dados têm o mesmo formato?
  • Isso poderia crescer sozinho no futuro?

Se a resposta for “sim”, merece outra planilha.

Criar e excluir planilhas (uso essencial)

Criar: clique no + ao lado das abas(Aba inferior, em baixo)
Use quando o conteúdo tem função diferente.

Excluir: Aperte o Botão Direito do Mouse na aba → Excluir
Use quando a planilha não tem mais propósito.

Criar não é bagunçar.
Criar é separar para organizar.

Renomear planilhas (isso é obrigatório)

Planilha chamada “Plan1” não comunica nada.

Bons nomes:

  • Vendas_2025
  • Produtos
  • Clientes
  • Resumo

Como fazer:

Duplo clique na aba → digite o nome → Enter

Gerenciar guias (organização visual)

As guias são o mapa do arquivo.

Boas práticas:

  • Dados brutos em uma planilha
  • Cálculos em outra
  • Resumos em outra

Exemplo lógico:

1. Dados
2. Cálculos
3. Resumo

Assim, qualquer pessoa entende o arquivo sem explicação.

Importância real da organização

Planilhas organizadas:

  • Evitam erro
  • Facilitam manutenção
  • Escalam com o tempo
  • Passam profissionalismo

Planilhas desorganizadas:

  • Funcionam hoje
  • Quebram amanhã
