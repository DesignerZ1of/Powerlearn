📘 LIÇÃO 25 — Métodos

🧠 Objetivo da aula

Agora você aprenderá:

> como fazer objetos executarem ações.

Até agora:

• objetos apenas guardavam informações.

Agora:

eles também poderão executar códigos.

📌 Conteúdos usados

• objetos
• função
• parâmetro
• this
• atualização de dados

🧠 Relembrando objeto
let jogador = { nome: "Carlos", moedas: 100 };
🧠 O que esse objeto faz?

Ele guarda:

• nome
• moedas

🚀 Entrando nos métodos

> Método é uma função dentro do objeto.

let jogador = { nome: "Carlos", falar: function() { console.log("Olá"); } };
🧠 O que mudou?

Agora o objeto:

> possui uma ação.

📌 falar
falar: function()

Isso é:

> um método.

🚀 Executando método
jogador.falar();

📌 Resultado

Olá
🧠 O que significa o . ?

O ponto serve para:

> acessar algo do objeto.

📌 Exemplos

🔹 acessar informação

jogador.nome

🔹 executar método

jogador.falar()
🚀 Método com atualização
let jogador = { nome: "Carlos", moedas: 100, adicionarMoedas: function(valor) { jogador.moedas = jogador.moedas + valor; } };
🧠 O que esse método faz?

Ele:

• recebe valor
• adiciona moedas
• atualiza o objeto

🚀 Executando
jogador.adicionarMoedas(50); console.log(jogador.moedas);

📌 Resultado

150
🚀 Entrando no this
🧠 O que é this?

O this significa:

> “esse objeto”.

let jogador = { nome: "Carlos", moedas: 100, adicionarMoedas: function(valor) { this.moedas = this.moedas + valor; } };
🧠 O que mudou?

Antes:

jogador.moedas

Agora:

this.moedas
🧠 Por que isso é importante?

Porque o método:

> usa os dados do próprio objeto.

🚀 Executando
jogador.adicionarMoedas(100); console.log(jogador.moedas);

📌 Resultado

200
🧠 Pensamento importante

> Métodos fazem objetos executarem ações automaticamente.

🎯 Fechamento

> Objetos guardam informações.
> Métodos criam ações para os objetos.
