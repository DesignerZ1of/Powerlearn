🧠 Relembrando if

O if serve para:

> verificar uma condição.

let idade = 18; if (idade >= 18) { console.log("Maior de idade"); }
🧠 O que acontece?

O sistema verifica:

idade >= 18

Se for verdadeiro:

> o código executa.

🧠 Relembrando else

> O else executa quando o if for falso.

let idade = 15; if (idade >= 18) { console.log("Maior de idade"); } else { console.log("Menor de idade"); }
🧠 Diferença importante

🔹 if

> executa quando a condição é verdadeira.

🔹 else

> executa quando a condição é falsa.

📌 Pensamento lógico

O sistema pensa:

se for verdadeiro → faça isso
senão → faça aquilo

🧠 Relembrando função

> Função serve para guardar um código para usar depois.

function mensagem() { console.log("Olá"); }
🚀 Executando função
mensagem();

📌 Resultado: Olá

🧠 Relembrando parâmetro

> parâmetro funciona como uma variável vazia esperando um valor.

function mensagem(nome) { console.log("Olá " + nome); }
🚀 Executando
mensagem("Carlos");

📌 Resultado: Olá Carlos

🧠 Atualização de dados

> atualizar valor significa mudar a informação antiga.

let moedas = 100; moedas = moedas + 50;
🧠 O que acontece?

Primeiro:

moedas = 100

Depois:

100 + 50

📌 Resultado final: 150

🎯 Pensamento importante

> Sistemas funcionam tomando decisões e atualizando informações.

🧠 Resumo da aula

🔹 if → verifica condição

🔹 else → executa quando o if falha

🔹 função → guarda código reutilizável

🔹 parâmetro → recebe valores

🔹 atualização → muda dados do sistema
