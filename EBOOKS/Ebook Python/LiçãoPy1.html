🐍 O que é Python?

Python é uma linguagem de programação usada para programar sistemas, inteligência artificial, jogos, sites e aplicativos.

Ela é muito famosa porque parece que você só está falando “inglês”.

🧠 COMO O PYTHON FUNCIONA

Irei falar algumas dicas e informações para você já entender a base dessa linguagem, o que é bom você sabe-las para te ajudar e dar uma mentalidade de programado de Python em pouco tempo só com essas informações.

Python lê o código:

de cima para baixo.

Essa informação é SUPER IMPORTANTE, você deve manter suas ideias organizadas, de cima para baixo, Python tem sua forma de ver seus códigos de forma própria o que diferencia de outras linguagens.

print("Linha 1")
print("Linha 2")
print("Linha 3")
▶ Linha 1
▶ Linha 2
▶ Linha 3

O computador executa exatamente nessa ordem.

⚠ O PYTHON FUNCIONA COM ESPAÇOS

Diferente de outras linguagens, o Python usa espaços para organizar o código, sendo a BASE dessa linguagem.

Isso se chama:

identação

if True:
    print("Funcionou")

Os espaços dizem:

💡 “esse print pertence ao if”
❌ Exemplo errado
if True:
print("Erro")
▶ IndentationError
🔥 A MELHOR DICA: Use os espaços corretamente. A estrutura da linguagem Python se baseia nos espaços, você sabendo usa-los corretamente você saberá 30% dessa linguagem, o que evitará erros e reescrita no futuro.
🔥 O comando print()

Nesta aula você já vai aprender o seu primeiro código.

O print(), ele serve para mostrar algo na tela.

Ou seja sempre que você quer saber se o código deu certo, ou só quer que apareça na tela, você o comando "print()".

Você deve colocar o texto dentro dos parênteses () e Somente quando for alguma palavra ou texto você usa as aspas "".

print("Olá, mundo!")
▶ Olá, mundo!
🧪 Mostrando textos
print("Python")
print("é")
print("muito")
print("legal")
🔢 Mostrando números
print(10)
print(50)
print(100)
📝 Texto usa aspas
✅ Correto

print("Olá")
❌ Errado

print(Olá)

Sem aspas o Python pensa que:

"Olá" é uma variável.
