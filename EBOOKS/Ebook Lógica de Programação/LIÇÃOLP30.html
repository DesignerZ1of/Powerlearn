🧠 Tipos de lógica que você aprendeu
🔹 Lógica de Verificação

Usada para:

verificar informações
tomar decisões
controlar sistemas

📌 Exemplos aprendidos
if (idade >= 18) if (moedas >= 50)
🧠 O que você aprendeu?

if
else
&&
||
verificações

🔹 Lógica de Repetição

Usada para:

repetir ações
percorrer arrays
automatizar sistemas

📌 Exemplos aprendidos
for (let i = 0; i < 5; i++) while (i < 5)
🧠 O que você aprendeu?

for
while
.length
repetição

🔹 Lógica de Organização

Usada para:

organizar informações
estruturar sistemas
deixar códigos mais limpos

📌 Exemplos aprendidos
let jogador = { nome: "Carlos", moedas: 100 };
🧠 O que você aprendeu?

objetos
arrays
arrays + objetos
organização de dados

🔹 Lógica de Atualização

Usada para:

alterar valores
atualizar sistemas
mudar estados

📌 Exemplos aprendidos
vida = vida - 10 moedas = moedas + 50
🧠 O que você aprendeu?

atualização de dados
mudança de valores
sistemas dinâmicos

🔹 Lógica de Sistemas

Usada para:

criar sistemas completos
conectar várias lógicas

📌 Exemplos aprendidos

sistema de compra
sistema de moedas
sistema de dano
sistema de recompensa

🧠 O que você aprendeu?

juntar códigos
pensar por etapas
organizar lógica

🔹 Lógica de Interação

Usada para:

responder ações do usuário
ativar sistemas
criar interface

📌 Exemplos aprendidos
onclick
🧠 O que você aprendeu?

eventos
clique
interação

🔹 Lógica POO

POO significa:

🧠 Programação Orientada a Objetos

🧠 O que ela faz?

Ela organiza sistemas usando:

objetos
propriedades
ações

📌 Exemplo aprendido
let jogador = { nome: "Carlos", moedas: 100 };
🧠 O que você aprendeu?

objetos
métodos
this
organização de sistemas
