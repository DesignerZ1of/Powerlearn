🧠 .length

📌 O que faz

Mostra:

> o tamanho do array.

📌 Estrutura

array.length

💻 Exemplo

let nomes = ["Ana", "Carlos", "João"]; console.log(nomes.length);

🧠 Resultado

3

🧠 .includes()

📌 O que faz

Verifica:

> se um valor existe no array.

📌 Estrutura

array.includes(valor)

💻 Exemplo

let nomes = ["Ana", "Carlos"]; console.log(nomes.includes("Ana"));

🧠 Resultado

true

🧠 .indexOf()

📌 O que faz

Procura:

> a posição do valor.

📌 Estrutura

array.indexOf(valor)

💻 Exemplo

let nomes = ["Ana", "Carlos", "João"]; console.log(nomes.indexOf("Carlos"));

🧠 Resultado

1

🧠 .splice()

📌 O que faz

Remove valores específicos do array.

📌 Estrutura

array.splice(posição, quantidade)

💻 Exemplo

let nomes = ["Ana", "Carlos", "João"]; nomes.splice(1, 1); console.log(nomes);

🧠 Resultado

["Ana", "João"]

🧠 Função

📌 O que faz

Cria:

> uma ação reutilizável.

📌 Estrutura

function nome() { }

💻 Exemplo

function falar() { console.log("Olá"); } falar();

🧠 Resultado

Olá

🧠 if

📌 O que faz

Verifica:

> uma condição.

📌 Estrutura

if (condição) { }

💻 Exemplo

let idade = 18; if (idade >= 18) { console.log("Maior"); }

🧠 else

📌 O que faz

Executa:

> quando o if for falso.

📌 Estrutura

if (condição) { } else { }

💻 Exemplo

let idade = 15; if (idade >= 18) { console.log("Maior"); } else { console.log("Menor"); }

🧠 Relembrando os símbolos

() guardam informações ou condições. {} guardam ações do código. ; finaliza instruções.
