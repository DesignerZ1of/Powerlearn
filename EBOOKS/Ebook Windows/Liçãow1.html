💻 Lição 1 — Instalando o Windows

⚠️ Atenção importante: Durante a instalação, você pode apagar tudo do computador dependendo da opção escolhida. 👉 Se tiver arquivos importantes, faça backup antes.

Instalar o Microsoft Windows é o primeiro passo para usar o computador de verdade. É um processo comum, seguro e que qualquer pessoa consegue fazer seguindo os passos.

⚙️ Antes de começar

👉 Você vai precisar de:

  • Um computador ou notebook
  • Um pendrive (mínimo 8GB)
  • Internet

💡 Todo computador pode instalar?

Quase todos sim.

Computadores mais novos → rodam versões atuais normalmente

Computadores mais antigos → podem ter limitações (ficar lento ou não suportar versões recentes)

👉 Ou seja: funciona na maioria, mas o desempenho depende do PC

🚀 Parte mais importante: Baixando o Windows (faça certo)

Aqui é onde muita gente erra.

Você deve baixar apenas pelo site oficial da Microsoft.

Passo a passo:

  • 1. Pesquise no Google: “Baixar Windows Microsoft”
  • 2. Entre no site oficial da Microsoft
  • 3. Procure por: “Baixar ferramenta de instalação” (Media Creation Tool)
  • 4. Clique em baixar

👉 Esse programa é o que vai preparar o pendrive automaticamente

🔌 Criando o pendrive de instalação
  • 1. Conecte o pendrive no computador
  • 2. Abra o programa que você baixou
  • 3. Aceite os termos
  • 4. Escolha: “Criar mídia de instalação”
  • 5. Selecione o pendrive
  • 6. Clique em avançar

⏳ Aguarde — ele vai baixar o Windows e configurar tudo sozinho

🔁 Iniciando a instalação (Boot)
  • 1. Reinicie o computador
  • 2. Assim que ligar, aperte várias vezes: F2, F12, DEL ou ESC (varia por PC)
  • 3. Vai aparecer uma tela de opções
  • 4. Escolha o pendrive

👉 Isso faz o computador iniciar pelo instalador

🧱 Instalando o Windows
  • 1. Escolha idioma e teclado
  • 2. Clique em “Instalar agora”
  • 3. Se pedir chave, você pode clicar em “Não tenho chave”
  • 4. Escolha a versão
  • 5. Selecione o disco (HD ou SSD)
  • 6. Clique em avançar

⏳ O sistema será instalado automaticamente (o PC reinicia algumas vezes)

🧠 Sobre as versões (explicado simples)

Home → uso comum (estudar, jogar, internet)

Pro → tem mais funções avançadas

👉 Se você não sabe qual escolher: vá de Home, já resolve tudo.

💸 Precisa pagar?

Não obrigatoriamente. Você pode instalar e usar o Windows normalmente sem ativar. Só ficam algumas limitações (como personalização e aviso na tela).

🔐 Segurança

É seguro se você:

  • Baixar pelo site oficial da Microsoft
  • Não usar arquivos de sites desconhecidos

Exercício — Numere as Etapas Corretamente

Digite o número correto para cada etapa da instalação:

Reiniciar o computador
Baixar a ferramenta no site da Microsoft
Escolher o disco e iniciar a instalação
Conectar o pendrive no computador
Escolher o idioma e clicar em “Instalar agora”
Aguardar o processo finalizar
Criar o pendrive de instalação
Entrar no boot e selecionar o pendrive
