🧩 Tipo de lógica usado

🔹 Lógica de Retorno

> Fazer a função entregar um resultado.

🧠 O que é return?

return serve para:

> devolver um valor da função.

📌 Ideia simples

A função:

executa algo
calcula algo
depois entrega o resultado

💻 Código (1º da aula)

function soma() { return 10 + 5; }

🧠 O que acontece?

A função:

calcula 10 + 5

devolve:

15

⚠️ Importante

O return:

> não mostra o valor sozinho.

Ele apenas:

> devolve o valor.

🚀 Mostrando o resultado

function soma() { return 10 + 5; } console.log(soma());

🧠 Resultado

15

🧠 Diferença importante

console.log() → mostra na tela return → devolve resultado

💻 Outro exemplo

function nome() { return "Carlos"; } console.log(nome());

🧠 Resultado

Carlos

🧠 Guardando o retorno

Você também pode guardar o resultado em variável.

💻 Exemplo

function soma() { return 20 + 10; } let resultado = soma(); console.log(resultado);

🧠 O que acontece?

a função devolve 30

variável guarda 30

depois mostra 30

📌 Como pensar no return

> A função entrega um resultado para fora dela.

⚠️ Erro comum

Pensar que:

> return mostra valores.

❌ Não.

Quem mostra:

console.log()

🧠 Estrutura

📌 Estrutura simples

function nome() { return valor; }

🧠 Fluxo simples

cria função função executa return devolve resultado código usa resultado

🧪 Pequena comparação

Sem return

function oi() { console.log("Olá"); }

👉 apenas mostra

Com return

function oi() { return "Olá"; }

👉 devolve valor

🎯 Fechamento

> Parâmetro recebe.
Função executa.
Return devolve resultado.
