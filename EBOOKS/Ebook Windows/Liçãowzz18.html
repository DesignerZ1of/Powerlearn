🌐 Lição 18 — Navegador (acessando a internet)

Agora que você já domina o computador, chegou a hora de usar algo essencial: a internet.

Para acessar sites, pesquisar e navegar, usamos um programa chamado navegador.

🌐 O que é um navegador

O navegador é o programa que permite acessar sites na internet.

👉 Sem ele, você não consegue:

Entrar em sites

Pesquisar

Usar serviços online

🚀 Como abrir o navegador

Você pode:

Clicar no ícone do navegador

Procurar pelo nome no computador

👉 Ao abrir, uma janela com a internet aparecerá.

🔗 Como acessar um site

Existem duas formas principais:

Digitando o endereço do site

Pesquisando pelo nome

🔍 O que você pode fazer

Pesquisar informações

Assistir conteúdos

Acessar contas

Usar serviços online

🧭 Entendendo a tela do navegador

Barra de endereço → onde você digita ou pesquisa

Página → onde o conteúdo aparece

Botões → voltar, avançar

⚠️ Cuidados básicos

Nem todo site é confiável

Evite clicar em qualquer coisa

Tenha atenção ao que acessa

🎯 Ideia principal da lição

O navegador é a porta de entrada para a internet.
