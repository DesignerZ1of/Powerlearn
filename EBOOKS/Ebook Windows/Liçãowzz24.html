📘 Lição 24 — Recuperação de conta e golpes

Agora que você já sabe criar e usar contas, precisa dominar duas coisas essenciais:

👉 recuperar acesso quando algo dá errado

👉 se proteger de tentativas de engano

🔄 Recuperação de conta

Você pode perder acesso quando:

Esquece a senha

Digita errado várias vezes

Sua conta é bloqueada

👉 Use “Esqueci minha senha”

🔐 Como recuperar uma conta

1. (Usando o navegador como o Google Chrome)Clique em “Esqueci minha senha”

2. Informe seu e-mail

3. Receba um código

4. Crie nova senha

Esse processo acontece no próprio site

⚠️ Cuidados importantes

Nunca compartilhe o código

Não confie em pedidos de senha

Faça no site oficial

🚨 Golpes

A Internet tem riscos, por isso se atente

TIPOS COMUNS:

Links perigosos

e-mails pedindo confirmação da conta

Mensagens com links suspeitos

Mensagens com promessas(dinheiro,prêmios)

🧠 Como identificar

Erros de escrita

Pressa ("Faça isso agora!!")

Pedidos de senha ou código

Links

🛡️ Como se proteger

Não clicar em links desconhecidos

Usar sites oficiais

Não informe senha para outras pessoas

Use senhas diferentes para cada plataforma

🎯 Ideia principal

Você precisa saber recuperar acesso e evitar golpes.
