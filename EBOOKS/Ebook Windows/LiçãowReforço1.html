🔁 Lição de Reforço — Revisando tudo que aprendemos

Antes de continuar avançando, é importante revisar o que já foi aprendido. Isso ajuda a fixar o conhecimento e evitar confusões no futuro.

Tudo até agora gira em torno de entender e usar o Microsoft Windows.

💻 O que é o Windows

O Windows é o sistema que faz o computador funcionar e permite que você use programas, abra arquivos e controle o computador.

Ele foi desenvolvido pela Microsoft e está presente na maioria dos computadores pessoais.

Sem um sistema operacional como o Windows, o computador não teria uma interface para ser usado.

⚙️ Instalação do Windows

Aprendemos que instalar o Windows é o primeiro passo para preparar um computador.

Para fazer isso normalmente é necessário:

Um computador

Internet

Um pendrive (geralmente de 8GB ou mais)

O processo básico envolve:

1. Baixar a ferramenta oficial da Microsoft

2. Criar um pendrive de instalação

3. Reiniciar o computador

4. Iniciar pelo pendrive

5. Seguir o processo de instalação

Durante a instalação você escolhe idioma, versão do sistema e o disco onde ele será instalado.

🛠 O que fazer depois da instalação

Conectar o computador à internet

Atualizar o sistema

Verificar se som, internet e tela estão funcionando

Instalar programas que você pretende usar

🖥 Conhecendo a tela do Windows

Área de trabalho — tela principal do computador.

Menu iniciar — encontra programas e configurações.

Barra de tarefas — mostra programas abertos.

Barra de pesquisa — procura arquivos e programas.

Explorador de arquivos — organiza arquivos e pastas.

🎨 Personalização

Alterar papel de parede

Modo claro ou escuro

Ajustar tamanho da tela

Fixar programas na barra

Alterar tela de bloqueio

🧾 Programas e aplicativos

Programas são ferramentas usadas para realizar tarefas.

Exemplos:

Navegar na internet

Escrever documentos

Ver fotos

Assistir vídeos

📂 Diferença entre programa e arquivo

Arquivo → conteúdo (foto, vídeo, documento)

Programa → ferramenta que abre o arquivo

🧠 O que acontece quando você usa o computador

1. Você dá um comando

2. O Windows recebe

3. Executa o programa

4. O programa aparece na tela

Quando um programa está aberto, ele está rodando.

🔄 Vários programas ao mesmo tempo

O Windows consegue gerenciar vários programas simultaneamente.

⚠️ Minimizar x Fechar

Minimizar → continua rodando

Fechar → encerra o programa
