🧠 Relembrando arrays + objetos
let jogadores = [ { nome: "Carlos", moedas: 100 }, { nome: "Ana", moedas: 200 } ];
🧠 O que isso faz?

O array:

> guarda vários objetos.

E cada objeto:

> representa um jogador.

🚀 Relembrando for
for (let i = 0; i < jogadores.length; i++) { console.log(jogadores[i].nome); }
🧠 O que o for faz?

percorre o array
pega cada jogador
mostra o nome

📌 Resultado

Carlos Ana
🚀 Relembrando atualização
jogadores[0].moedas = jogadores[0].moedas + 50;
🧠 O que acontece?

O sistema:

pega moedas atuais
adiciona valor
atualiza informação

🚀 Relembrando if
if (jogadores[0].moedas >= 100) { console.log("Pode comprar"); }
🧠 O que o sistema verifica?

Se o jogador:

> possui moedas suficientes.

🚀 Relembrando função
function recompensa(valor) { }
🧠 O que a função faz?

Ela guarda:

> um código reutilizável.

🚀 Sistema completo da aula

Agora iremos criar:

🎮 Sistema de recompensa e dano

🚀 ETAPA 1 — Criando jogadores
let jogadores = [ { nome: "Carlos", moedas: 100, vida: 100 }, { nome: "Ana", moedas: 200, vida: 80 } ];
🚀 ETAPA 2 — Criando recompensa
function recompensa(valor) { for (let i = 0; i < jogadores.length; i++) { jogadores[i].moedas = jogadores[i].moedas + valor; } }
🧠 O que essa função faz?

Ela:

Percorre jogadores e adiciona moedas para todos.

🚀 ETAPA 3 — Criando dano
function dano(valor) { for (let i = 0; i < jogadores.length; i++) { jogadores[i].vida = jogadores[i].vida - valor; } }
🧠 O que essa função faz?

Ela:

Percorre jogadores e remove vida de todos.

🚀 ETAPA 4 — Verificando morte
for (let i = 0; i < jogadores.length; i++) { if (jogadores[i].vida <= 0) { console.log(jogadores[i].nome + " morreu"); } }
🧠 O que acontece?

O sistema verifica:

> quais jogadores morreram.

🚀 ETAPA 5 — Código final completo
let jogadores = [ { nome: "Carlos", moedas: 100, vida: 100 }, { nome: "Ana", moedas: 200, vida: 80 } ]; function recompensa(valor) { for (let i = 0; i < jogadores.length; i++) { jogadores[i].moedas = jogadores[i].moedas + valor; } } function dano(valor) { for (let i = 0; i < jogadores.length; i++) { jogadores[i].vida = jogadores[i].vida - valor; } } recompensa(50); dano(90); for (let i = 0; i < jogadores.length; i++) { if (jogadores[i].vida <= 0) { console.log(jogadores[i].nome + " morreu"); } else { console.log(jogadores[i]); } }
🧠 O que o sistema completo faz?

🔹 Adiciona moedas

🔹 Remove vida

🔹 Percorre jogadores

🔹 Verifica morte

🔹 Mostra resultado final

🎯 Pensamento importante

> Sistemas grandes são várias pequenas lógicas funcionando juntas.
