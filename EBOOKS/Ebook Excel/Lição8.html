Lição 8 — Organização de Dados

📘 O que vamos aprender?

Quando trabalhamos com muitas informações, tudo pode virar uma bagunça. Imagine uma empresa com centenas de nomes, produtos e valores misturados. Se os dados não estiverem organizados, encontrar informações importantes fica difícil.

Nesta lição você aprenderá como o Excel ajuda a:

  • ✔ Colocar dados em ordem
  • ✔ Mostrar apenas o que importa
  • ✔ Remover informações repetidas
  • ✔ Transformar listas em tabelas profissionais

E o melhor: você aprenderá praticando diretamente em uma simulação parecida com o Excel real.

🟨 PASSO 1 — Entendendo a Bagunça

Observe a tabela acima. Os nomes estão misturados, existem produtos repetidos e algumas informações aparecem duas vezes.

Quando uma empresa trabalha com muitos dados assim, fica difícil:

  • Encontrar pessoas rapidamente
  • Analisar produtos específicos
  • Evitar erros em relatórios

Por isso o Excel possui ferramentas de organização.

🟩 PASSO 2 — Classificar Dados

Classificar significa colocar as informações em ordem.

Como fazer:

  1. Clique em qualquer parte da tabela
  2. Abra a guia Dados
  3. Clique em Classificar A-Z

✨ Resultado: os nomes ficarão organizados em ordem alfabética.

Isso ajuda muito quando precisamos encontrar informações rapidamente.

🟩 PASSO 3 — Usando Filtros

Filtros servem para mostrar apenas as informações importantes.

Experimente:

  1. Clique em Filtro
  2. Aperte a seta da coluna Produto
  3. Deixe marcado apenas “Caneta”

✨ Resultado: somente as linhas com Caneta aparecerão.

O restante continua guardado, apenas escondido temporariamente.

🟩 PASSO 4 — Remover Duplicatas

Às vezes os mesmos dados aparecem repetidos. Isso pode causar erros em contas e relatórios.

Experimente:

  1. Abra a guia Dados
  2. Clique em Remover Duplicatas

✨ Resultado: uma das linhas da Ana será apagada.

Agora a tabela ficará mais limpa e organizada.

🎯 O que você aprendeu

  • ✔ Organizar informações em ordem
  • ✔ Filtrar dados importantes
  • ✔ Remover repetições
  • ✔ Trabalhar de forma profissional

📌 Organização de dados significa controlar a bagunça para analisar informações com facilidade.
