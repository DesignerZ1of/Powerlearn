Agora vamos juntar tudo isso e conhecer melhor uma ferramenta muito importante do Microsoft Windows: o Explorador de Arquivos.

Essa ferramenta é responsável por mostrar onde estão os arquivos e pastas do computador.

📂 O que é o Explorador de Arquivos

O Explorador de Arquivos é o lugar onde você pode ver, organizar e acessar arquivos e pastas dentro do computador.

É através dele que você consegue:

Abrir arquivos

Ver pastas

Organizar documentos

Mover arquivos de um lugar para outro

Normalmente ele é representado por um ícone de pasta 📁 na barra de tarefas ou no menu iniciar.

🗂️ Onde ficam os arquivos

Documentos → arquivos de texto e trabalhos

Imagens → fotos e imagens

Downloads → arquivos baixados da internet

Vídeos → arquivos de vídeo

🧭 Como navegar pelas pastas

1. Abra o Explorador de Arquivos

2. Clique em uma pasta

3. Veja o conteúdo que está dentro dela

4. Clique em outra pasta para continuar navegando

🔁 Como mover arquivos (muito importante)

1. Abra o Explorador de Arquivos

2. Encontre o arquivo que deseja mover

3. Clique no arquivo e segure o botão do mouse

4. Arraste o arquivo até a pasta desejada

5. Solte o arquivo dentro da pasta

Pronto, o arquivo foi movido para outro local.
