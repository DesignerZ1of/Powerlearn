📘 LIÇÃO 29 — Conversão de Valores

🧠 Objetivo da aula

Agora você aprenderá:

> como transformar valores.

Isso é muito importante porque:

inputs normalmente vêm como texto

sistemas precisam trabalhar com números

às vezes o JavaScript junta textos sem querer

📌 Conteúdos usados

Number()
String()
soma
texto
números

🧠 Relembrando tipos de valores

🔹 Texto

"10"

🔹 Número

10
🧠 Parece igual…

Mas NÃO é igual.

🚀 Problema comum
console.log("10" + 5);

📌 Resultado

105
🧠 Por que aconteceu isso?

Porque:

"10"

É texto.

Então o JavaScript:

> juntou os valores.

🚀 Entrando no Number()
🧠 O que faz?

Number() transforma:

> texto em número.

console.log(Number("10") + 5);

📌 Resultado

15
🧠 O que aconteceu?

Agora:

"10"

Virou:

10
🚀 Outro exemplo
let moedas = "100"; moedas = Number(moedas); moedas = moedas + 50; console.log(moedas);

📌 Resultado

150
🧠 Pensamento importante

> Sistemas precisam saber quando algo é texto ou número.

🚀 Entrando no String()
🧠 O que faz?

String() transforma:

> valor em texto.

console.log(String(10));

📌 Resultado

"10"
🚀 Misturando texto
let moedas = 100; console.log("Moedas: " + moedas);

📌 Resultado

Moedas: 100
🧠 O que aconteceu?

O JavaScript:

> transformou o número em texto automaticamente.

🚀 Sistema simples

Agora iremos criar:

🎮 Sistema de compra com conversão

let moedas = "100"; function comprar(valor) { moedas = Number(moedas); moedas = moedas - valor; console.log(moedas); } comprar(30);

📌 Resultado

70
🧠 O que esse sistema faz?

recebe valor como texto

transforma em número

realiza conta

atualiza moedas

🎯 Pensamento importante

> Conversão evita erros nos sistemas.
