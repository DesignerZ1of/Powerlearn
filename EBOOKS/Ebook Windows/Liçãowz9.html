🔎 Lição 9 — Pesquisar programas e arquivos

Com o tempo, conforme você usa o computador, mais programas e arquivos vão sendo adicionados ao sistema. Por isso, procurar algo manualmente pode se tornar difícil. Para resolver isso, o Microsoft Windows possui uma ferramenta de pesquisa, que permite encontrar rapidamente programas, arquivos e outras ferramentas do computador.

🔍 Pesquisando programas

Uma das formas mais rápidas de abrir um programa é utilizando a pesquisa do Windows.

Como fazer:

1. Clique no Menu Iniciar ou na barra de pesquisa

2. Comece a digitar o nome do programa

3. O sistema mostrará os resultados encontrados

4. Clique no programa para abrir

Por exemplo, se você digitar Google Chrome, o navegador aparecerá nos resultados e poderá ser aberto rapidamente.

📂 Pesquisando arquivos

A ferramenta de pesquisa também pode ser usada para encontrar arquivos que estão salvos no computador.

Como funciona:

1. Abra a barra de pesquisa

2. Digite o nome do arquivo ou parte dele

3. O Windows procurará nas pastas do computador

4. Os resultados aparecerão na tela

Isso é muito útil quando você não lembra exatamente onde salvou um arquivo.

📑 Tipos de arquivos

Durante uma pesquisa, você pode encontrar diferentes tipos de arquivos. Cada tipo possui uma função específica dentro do computador.

Alguns exemplos comuns são:

PDF → documentos digitais

JPG / PNG → imagens ou fotos

MP3 → arquivos de música

MP4 → vídeos

DOCX → documentos de texto

👉 É importante gravar e reconhecer esses tipos, pois eles aparecem com muita frequência no uso do computador.

🎯 Ideia principal da lição

A ferramenta de pesquisa do Windows ajuda você a encontrar rapidamente programas e arquivos no computador.

Em vez de procurar manualmente em várias pastas, basta digitar o nome do que você procura, e o sistema mostrará os resultados disponíveis.
