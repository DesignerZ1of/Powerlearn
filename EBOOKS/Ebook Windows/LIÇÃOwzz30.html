🖥️ Lição 30 — Área de trabalho virtual

Agora você vai aprender um recurso mais avançado do Microsoft Windows:

👉 usar mais de uma área de trabalho no mesmo computador


🖥️ O que é área de trabalho virtual

É como ter várias áreas de trabalho diferentes dentro do mesmo computador.

🧠 Exemplo:

Área 1 → estudo

Área 2 → lazer

Área 3 → organização

🎯 Para que serve

Evitar bagunça, separar tarefas e melhorar foco.

⚙️ Como usar

Clique no botão de visão de tarefas ou use Windows + Tab

🎯 Ideia principal

Área de trabalho virtual é organização avançada da tela.

Objetivo:
