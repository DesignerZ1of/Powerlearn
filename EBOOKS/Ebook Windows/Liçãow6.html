🧠 Lição 6 — O que está acontecendo dentro do computador

Agora você já sabe que usa programas dentro do Microsoft Windows.

Essa lição não é sobre clicar. É sobre entender o jogo por trás da tela.

👉 O computador não faz nada sozinho. Ele executa exatamente o que você manda.

Entender isso é o que separa quem clica… de quem entende.

⚙️ O que acontece quando você clica em algo

1. Você clica em um programa

2. O Windows recebe o comando

3. Ele carrega o programa na memória

4. O programa abre na tela

💡 Clique → comando → execução
🧠 O que significa “programa rodando”

Quando um programa está aberto, ele está em execução.

Mesmo que você não veja.

👉 Exemplos:

Minimizado → ainda está rodando

Em segundo plano → ainda está rodando

💡 Ele só para quando você fecha de verdade.

🔄 Vários programas ao mesmo tempo

O computador consegue rodar vários programas juntos.

Exemplo:

Navegador aberto

Música tocando

Arquivo aberto

👉 Tudo ao mesmo tempo.

⚠️ Minimizar ≠ Fechar

Minimizar → só esconde

Fechar → encerra

🧱 Por que o PC trava às vezes?

Muitos programas abertos

Programa pesado

Pouca memória

🔍 O que significa “carregando”

O sistema está processando algo ou buscando informações.

🧠 Quem controla tudo?

Windows → controla o sistema

Programas → fazem tarefas

Você → dá os comandos

👉 Você é o centro de tudo.
