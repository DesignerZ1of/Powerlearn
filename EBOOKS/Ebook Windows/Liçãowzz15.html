🧠 Lição 15 — Propriedades dos arquivos

📄 O que são propriedades

Todo arquivo possui informações além do nome.

Exemplos:
Tamanho
Tipo
Data de criação
Última modificação

👉 São dados que ajudam a entender melhor o arquivo.

--- 🖱️ Como ver as propriedades

1. Clique com o botão direito no arquivo
2. Clique em Propriedades

Uma janela será aberta com todas as informações.

--- 📦 Tamanho do arquivo

Mostra quanto espaço o arquivo ocupa.

👉 Exemplos:
Texto → pequeno
Imagem → médio
Vídeo → grande

Isso ajuda a entender o uso do armazenamento.

--- 📅 Data de modificação

Mostra a última vez que o arquivo foi alterado.

👉 Útil para:
Identificar versão mais recente
Saber se o arquivo foi atualizado

--- 📑 Tipo do arquivo

Mostra qual é o formato do arquivo.

👉 Exemplo:
Documento
Imagem
PDF

Ajuda a saber com qual programa abrir.

--- 🎯 Ideia principal

Um arquivo não é só o nome.

Ele possui informações importantes que ajudam você a identificar, organizar e usar melhor o que está no computador.
