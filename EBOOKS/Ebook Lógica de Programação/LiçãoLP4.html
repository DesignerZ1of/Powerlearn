Aprendemos como criar uma variável (Variável é uma caixa que guardar informações)

let NomeDaVariável = 10;

let → Comando para criar a variável

= → Significa recebe esse valor

IMPORTANTE📌

O que significa o ";" (ponto e vírgula)?

→ Nós usamos ele para finalizar uma ação, na qual é a de criar uma variável.

É como se ele dissese:

“Essa ação terminou, pode ir pra próxima”

E nós usamos ele para criar a variável e para mostra la (aprendemos na lição 3)

console.log(NomedaVariável);

Nesse código usamos tambem o ";" E tambem usamos outros componentes:

console.log → Comando para mostrar a variável

() → Dentro dos parenteses nós colocamos o nome da variável desejada

E finalizamos com ";"
