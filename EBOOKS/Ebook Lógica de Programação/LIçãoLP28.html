📘 LIÇÃO 28 — Eventos

🧠 Objetivo da aula

Agora você aprenderá:

> como fazer o usuário interagir com o sistema.

Até agora:

os códigos executavam sozinhos

Agora:

o usuário poderá ativar ações

📌 Conteúdos usados

HTML
botão
função
evento
onclick

🧠 O que é um evento?

Evento é:

> algo que acontece no sistema.

📌 Exemplos

clique
tecla apertada
mouse passando
enviar formulário

🧠 O mais usado no começo

O mais usado:

click

🚀 Criando botão

💻 Código HTML

<button>Entrar</button>
🧠 O que isso cria?

Cria:

> um botão na tela.

🚀 Entrando no onclick
🧠 O que é onclick?

onclick significa:

> quando clicar.

<button onclick="mensagem()"> Entrar </button>
🧠 O que acontece?

Quando clicar:

> a função será executada.

🚀 Criando função
function mensagem() { console.log("Olá"); }
🚀 Código completo
<button onclick="mensagem()"> Entrar </button> <script> function mensagem() { console.log("Olá"); } </script>
🧠 O que esse sistema faz?

cria botão
espera clique
executa função

🚀 Atualizando informações

Agora iremos misturar:

evento
atualização de dados

<button onclick="ganharMoedas()"> Ganhar moedas </button> <script> let moedas = 100; function ganharMoedas() { moedas = moedas + 50; console.log(moedas); } </script>
🧠 O que acontece?

Cada clique:

> adiciona moedas.

📌 Resultado

Clique 1:

150

Clique 2:

200
🧠 Pensamento importante

> Eventos fazem o usuário controlar o sistema.

🚀 Misturando objeto
<button onclick="cura()"> Curar </button> <script> let jogador = { nome: "Carlos", vida: 50 }; function cura() { jogador.vida = jogador.vida + 20; console.log(jogador.vida); } </script>
🧠 O que esse sistema faz?

Quando clicar:

aumenta vida
atualiza objeto
mostra resultado

🎯 Ideia importante

> Eventos conectam a lógica com a interface.

🚀 DESAFIO DA AULA

Crie:

botão de ganhar moedas

botão de tomar dano

objeto jogador

funções para atualizar dados

🎯 Fechamento

> Eventos fazem sistemas responderem às ações do usuário.
