📑 Lição 12 — Tipos de arquivos (entendendo cada um)

Agora que você já sabe criar pastas e arquivos no Microsoft Windows, é essencial entender que cada arquivo tem um tipo e uma função específica.

Saber identificar isso evita erros, ajuda a abrir corretamente e melhora muito o uso do computador.

📄 Documento de texto

Esse tipo de arquivo é usado para escrever e editar conteúdo.

👉 Usado para:

Trabalhos escolares

Anotações

Redações

Exercícios

Normalmente pode ser criado dentro de programas de texto ou diretamente no sistema.

💡 Características:

Pode ser editado facilmente

Permite adicionar texto, às vezes imagens

Pode ser salvo com nomes personalizados

👉 Exemplo de uso:

Você faz um trabalho da escola e salva como um documento.

🗜️ Pasta compactada (ZIP)

Esse tipo de arquivo serve para juntar vários arquivos em um só.

👉 Usado para:

Enviar vários arquivos juntos

Economizar espaço

Organizar downloads

💡 Características:

Fica com formato “fechado”

Precisa ser extraído para acessar tudo dentro

Pode conter vários arquivos e pastas

👉 Exemplo de uso:

Você baixa um pacote com vários arquivos → vem tudo dentro de uma pasta compactada.

🖼️ Imagem (JPG / PNG)

Arquivos de imagem são usados para guardar fotos e figuras.

👉 Usado para:

Fotos do celular

Imagens da internet

Trabalhos visuais

💡 Características:

Não é feito para escrever

Apenas visualizar ou editar em programas específicos

Muito comum no dia a dia

👉 Exemplo de uso:

Você baixa uma imagem → abre e visualiza no computador.

🎵 Áudio (MP3)

Arquivos de áudio são usados para som.

👉 Usado para:

Música

Gravações de voz

Aulas em áudio

💡 Características:

Só reproduz som

Pode ser aberto em players de música

Não possui imagem

👉 Exemplo de uso:

Você baixa uma música → abre e escuta.

🎥 Vídeo (MP4)

Arquivos de vídeo são usados para imagem + som juntos.

👉 Usado para:

Filmes

Aulas

Vídeos gravados

💡 Características:

Possui imagem em movimento

Possui áudio

Normalmente ocupa mais espaço

👉 Exemplo de uso:

Você baixa uma aula → abre e assiste.

📑 PDF

Arquivo muito comum para documentos prontos.

👉 Usado para:

Apostilas

Livros digitais

Contratos

Materiais escolares

💡 Características:

Mantém o formato original (não desconfigura)

Não é fácil de editar

Ideal para leitura

👉 Exemplo de uso:

Você recebe um material → abre e lê sem alterar.

⚙️ Arquivo de programa (executável)

Esse tipo de arquivo serve para instalar ou iniciar programas.

👉 Usado para:

Instalar aplicativos

Abrir programas diretamente

💡 Características:

Pode alterar o sistema

Deve ser usado com cuidado

Sempre verificar a origem

👉 Exemplo de uso:

Você baixa um programa → abre o arquivo → começa a instalação.

🎯 Ideia principal da lição

Cada tipo de arquivo existe para uma função específica.

Você não precisa decorar todos, mas deve reconhecer principalmente:

Documento de texto

PDF

Imagem (JPG)

Pasta compactada (ZIP)

Isso já permite usar o computador com muito mais segurança e entendimento.
