🧠 let

📌 O que faz

Cria uma variável.

O que é uma variável?

Variáveis são caixas que guardam informações elas são importante pra o funcionamento do código

Mas o por que guardar uma informação?

Tudo que fazemos deve estar guardado no sistema, por exemplo:

🖥 Verificação de Idade

Você guarda a idade para:

verificar se pode entrar
comparar com 18

Quando alguém digita sua idade isso é considerado uma variável. Ou seja estaria guardando a informação para usar depois na comparação

---
💻 CÓDIGO
let numero = 10;
🧠 Tradução

Crie uma variável chamada “numero” e guarde 10

---
🧠 console.log()

📌 O que faz

Mostra informações no console.

Serve para ver valores e testar lógica.

💻 Exemplo
let numero = 10; console.log(numero);
🧠 Resultado

Aparece 10

💡 Quando usar

ver resultado
testar variável
entender o que o código está fazendo

---
🧠 while

📌 O que faz

Repete uma ação enquanto uma condição for verdadeira.

Pode ser usado em sites da seguinte forma:

🪪 Verificação de Senha

Enquanto não tiver acertado a senha, continuará pedindo a senha.

⏰ Temporizador

Começa no 5 e vai diminuindo até o 0

---
💻 Código (Base)
let numero = 1; while (numero <= 3) { console.log(numero); numero = numero + 1; }
🧠 Como funciona

começa em 1
verifica condição
mostra valor
atualiza valor
repete

---
💡 Quando usar while

Use quando:

você NÃO sabe exatamente quantas vezes vai repetir

---
📌 Exemplo mental

Enquanto algo continuar acontecendo → continue repetindo

---
🧠 for

📌 O que faz

Também é repetição.

Mas:

O for é usado quando você já sabe quantas vezes quer repetir algo.

O for é bem estruturado pois ele junta:

início
condição
mudança

em uma única estrutura.

Por isso:

Fica mais fácil de ler
Mais rápido de entender
Melhor para contagens

💻 Exemplo
for (let i = 1; i <= 3; i++) { console.log(i); }
---
🧠 Como funciona

começa no 1
continua até 3
aumenta +1
repete

---
💡 Quando usar for

Use quando:

você JÁ sabe quantas vezes vai repetir

---
🔍 Diferença real

while

Mais manual
Não sabe exatamente as vezes em que vai repetir

---

for

Mais organizado
É tudo em 1 linha só
Já sabe quantas vezes vai repetir.

---
🧠 Sobre o ;

O ; (ponto e vírgula) serve para finalizar uma instrução.

É como um ponto final no código.

Ele ajuda o programa a entender:

“essa parte terminou”

---
🧠 Sobre o ( )

Os parênteses ( ) normalmente guardam:

condições
informações
parâmetros

Eles ajudam a organizar o que será usado.

---
🧠 Sobre as { }

As chaves { } criam um bloco de código. Tudo que está dentro pertence à mesma estrutura.

Elas agrupam ações.

🧪 Exercício 1 — WHILE

Crie um código usando while para mostrar:

1, 2, 3

💡 EXEMPLO PARA SEGUIR:
let numero = 1; while(numero <= 3){ console.log(numero); numero = numero + 1; }

🧪 Exercício 2 — FOR

Crie um código usando for para mostrar:

1, 2, 3

💡 EXEMPLO PARA SEGUIR:
for(let i = 1; i <= 3; i++){ console.log(i); }
