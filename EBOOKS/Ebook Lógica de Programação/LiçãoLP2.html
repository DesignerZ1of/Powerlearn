📘 LIÇÃO 2 — Variáveis

🧠 O que são variáveis?

Variáveis são espaços para guardar informações.

> O programa precisa lembrar de coisas. Variável é a memória dele.

📦 Exemplo simples
let nome = "João";
let idade = 18;

👉 Aqui você guardou informações:

nome → "João"

idade → 18

🧱 Erro comum

Achar que variável é fixa.

> Não é.Ela muda o tempo todo.

Usando o Exemplo da *Lição1:*

Se a idade for maior ou igual a 18- Pode entrar
Senão- Não pode entrar

⚙️Onde as Variaveis entra?

A Variavel vai servir para guardar a idade da pessoa, para depois falar se pode ou não entrar.

Porque pensa:

> Como o sistema vai decidir algo sem saber a idade?

É a Variável que permite a lógica acontecer, pois sem ela:

Não tem Idade
Não tem Comparação
Não tem Decisão

> *Mas como então agente pode declarar a variável?*

Forma Básica (JavaScript)
let idade = 18

let → Você está criando a variável

idade → nome da variável

= → Significa "recebe"

18 → Valor guardado

*Ou seja quando você for criar uma variável faça dessa forma:*

(let) (nome que você irá inserir em sua variável) (=) (Valor da variável)
