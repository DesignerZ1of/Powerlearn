🧾 Lição 5 — Programas e Aplicativos (O que você realmente está usando)

Até agora você instalou o Microsoft Windows e conheceu a tela.

Agora vem algo essencial:

Você não usa “o computador”. Você usa programas dentro do Windows.

Se entender isso, tudo começa a fazer sentido.

💡 O que é um programa?

Programa (ou aplicativo) é toda ferramenta que você abre para fazer algo.

Exemplos:

  • Navegar na internet → Google Chrome
  • Escrever textos → Word
  • Jogar → Jogo
  • Ver fotos → Visualizador de imagens

👉 Sempre que você clica e algo abre, aquilo é um programa.

📂 Arquivo não é programa (essa parte é importante)

Muita gente confunde.

📄 Arquivo

  • PDF
  • Foto
  • Vídeo
  • Documento

🛠 Programa

  • PDF → precisa de leitor de PDF
  • Foto → precisa de visualizador
  • Documento → precisa de editor
💡 Regra simples: O programa abre o arquivo.
🔎 Onde ficam os programas?
  • No Menu Iniciar
  • Na barra de tarefas
  • Na área de trabalho
  • Pesquisando pelo nome

Se você instalou algo e não encontra, pode usar a barra de pesquisa.

🧠 O que acontece quando você abre um programa?

1. O Windows executa o programa

2. Ele passa a rodar na memória

3. Ele aparece em forma de janela

Mesmo minimizado, ele continua funcionando.

👉 Minimizar não é fechar.
⚠️ Erros comuns que essa lição evita
  • Achar que arquivo é programa
  • Minimizar e pensar que fechou
  • Não entender o que está aberto
  • Instalar coisa sem saber o que é
