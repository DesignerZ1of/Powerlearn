🧠 O que são loops?

Loop significa: repetição

Eles servem para repetir código várias vezes sem precisar escrever tudo manualmente.

❌ Sem loop
print("Olá") print("Olá") print("Olá") print("Olá")

Isso funciona… mas fica repetitivo.

✅ Com loop
for i in range(4): print("Olá")
▶ Olá
▶ Olá
▶ Olá
▶ Olá
⚠ Python usa espaços (identação) para organizar os blocos.
🔥 O loop for

O for serve para: repetir algo uma quantidade definida de vezes.

for i in range(5): print(i)
▶ 0
▶ 1
▶ 2
▶ 3
▶ 4
🔥 O loop while

O while repete: enquanto algo for verdadeiro.

numero = 1 while numero <= 5: print(numero) numero = numero + 1
▶ 1
▶ 2
▶ 3
▶ 4
▶ 5
💡 No Python os espaços são obrigatórios.
Sem espaços corretos o código gera erro.
