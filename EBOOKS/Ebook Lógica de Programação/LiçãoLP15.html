🧠 O que é uma função?

Função é:

> um bloco de código que executa uma ação.

📌 Ideia simples

Você cria uma ação uma vez… e pode usar várias vezes.

💻 Código (1º da aula)

function falar() { console.log("Olá"); }

🧠 O que significa cada parte

🔹 function

Serve para:

> criar a função

🔹 falar

É o nome da função.

🔹 ( )

Parênteses da função.

🔹 { }

Guardam as ações da função.

⚠️ Importante

Criar a função:

> NÃO executa ela automaticamente.

🚀 Como executar a função

falar();

🧠 Resultado

Aparece:

Olá

📌 Como pensar em função

Função funciona como:

> um botão de ação

Quando você chama:

> ela executa tudo que está dentro.

💻 Exemplo completo

function falar() { console.log("Olá"); } falar(); falar(); falar();

🧠 O que acontece

A função executa:

> 3 vezes
