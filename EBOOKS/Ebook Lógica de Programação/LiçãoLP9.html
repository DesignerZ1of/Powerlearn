---
🧩 Tipo de lógica usado

🔹 Lógica Condicional

O programa toma decisões usando várias condições.

---
🧠 O que é &&

&& significa:

“e”

---
📌 Como funciona

As duas condições precisam ser verdadeiras.

---
💻 Código (1º da aula)
let idade = 20; let dinheiro = 50; if (idade >= 18 && dinheiro >= 30) { console.log("Pode entrar"); }
---
🧠 Tradução

Se a idade for maior ou igual a 18 E tiver pelo menos 30 de dinheiro → pode entrar

---
⚠️ Importante

Com &&:

tudo precisa estar correto

---
🧠 O que é ||

|| significa:

“ou”

---
📌 Como funciona

Só uma condição precisa ser verdadeira.

---
💻 Código (2º da aula)
let vip = false; let ingresso = true; if (vip == true || ingresso == true) { console.log("Pode entrar"); }
---
🧠 Tradução

Se for VIP OU tiver ingresso → pode entrar

---
🔍 Diferença mais importante

&&

Todas precisam ser verdadeiras

---

||

Apenas uma precisa ser verdadeira

---
🧠 Onde isso é usado?

sistemas de login

verificações de acesso

jogos

permissões

compras

validações

---
📌 Comparação simples

&&

“isso E aquilo”

||

“isso OU aquilo”
