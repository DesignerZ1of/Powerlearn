Lição 3 — Formatação que Faz Sentido

Na lição de hoje, vamos aprender sobre ferramentas que irão te ajudar a destacar células importantes; de forma que você possa achar de forma mais rápida ou destacar algum tema importante. Ferramentas que serão aprendidas: Alinhamento, Fonte, Preenchimento.

1️⃣ Alinhamento

O que faz: Posiciona o dado dentro da célula.

Como usar:
1. Selecione a célula que quer alinhar (ex: B2)
2. Aperte em Página Inicial → Alinhamento → e escolha entre: esquerda, direita ou centro

Exemplo prático:
Nomes → esquerda
Valores → direita
Títulos → centro

Use o alinhamento como uma forma de organizar ideias dentro de uma célula.
2️⃣ Fonte

O que faz: Ajusta tipo, tamanho e destaque do texto.

Como usar:
1. Selecione as células (ex: A1)
2. Aperte em Página Inicial → E escolha: Fonte, negrito ou tamanho

Exemplo prático:
Títulos → negrito e maior
Dados → fonte padrão

Use para destacar títulos ou temas de suas planilhas.

Atalho

Nós podemos usar o seguinte atalho: Aperte com o Butão Direito do Mouse → e Escolha a Fonte, aplique o negrito, ou aumente o tamanho

3️⃣ Preenchimento

O que faz: Colore as células para diferenciar dados sem poluir a planilha.

Como usar:
1. Selecione as células(C1 ou B2)
2. Aperte em Página Inicial → Cor de Preenchimento → e escolha a cor

Exemplo prático:
Categorias → cinza claro
Valores importantes → amarelo suave

Elas são importantes para uma melhor visualização; ou seja, caso queira achar dados mais rápidos você pode colorir as células usando essa ferramenta.

Atalho

Nós podemos usar o seguinte atalho: Aperte com o Butão Direito do Mouse → e Escolha a Cor de Preenchimento
🔑 Dica final: unindo tudo

1. Selecione corretamente os dados (Aula 2)
2. Aplique alinhamento → facilita leitura
3. Ajuste fonte → destaca informação
4. Use cores e estilos → organiza visualmente
